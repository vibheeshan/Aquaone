# 🌊 AquaOne

### AI-Powered Citizen Science & One Health Intelligence Platform

**AquaOne** is an AI-powered environmental intelligence platform designed to help citizens monitor freshwater streams, transform observations into meaningful insights, identify environmental risks, and connect environmental information with broader One Health context.

> **Observe. Validate. Understand. Predict. Protect.**

---

## 🌍 About AquaOne

Urban streams and freshwater ecosystems are affected by pollution, biodiversity loss, waste, environmental changes, and other environmental pressures.

Citizens can provide valuable observations, but collecting observations alone is not enough.

The real challenge is transforming those observations into:

**Reliable Data → Environmental Insights → Risk Prediction → Early Warning → Community Action**

AquaOne addresses this challenge by connecting citizen science, artificial intelligence, environmental analytics, prediction, storytelling, community engagement, and interoperability into **one unified platform**.

---

## 💡 Our Solution

AquaOne connects different users through a common environmental intelligence platform.

Citizens can collect stream observations and photographs through a simple guided assessment.

AI can assist in validating the submitted information by checking for inconsistencies, anomalies, image quality, and possible environmental indicators.

Experts can review AI-assisted results before they become verified environmental information.

The verified information can then be transformed into stream intelligence, risk predictions, alerts, stories, and One Health insights.

# 💡 Inspiration

AquaOne was inspired by a simple question:

> **What if ordinary citizens could observe changes in their local streams and immediately understand what those observations mean?**

Citizen science can generate valuable information, but its impact becomes greater when the information can be validated, analyzed, explained, and connected to decisions.

This idea led to the development of AquaOne.

---

# 🚧 Challenges

One of the biggest challenges was connecting **seven different challenge tracks into one coherent platform**.

Instead of creating seven disconnected applications, AquaOne organizes the functionality around four user-focused dashboards.

Another challenge was making AI trustworthy.

To address this, AquaOne emphasizes:

- Confidence information
- Explainability
- Human review
- Auditability
- Data provenance
- Human overrides

Another challenge was transforming raw environmental observations into information that different users can understand.

The platform therefore separates the process into different stages of observation, validation, intelligence, prediction, and action.

## 🚀 Quick Start Guide (Local Running)

### 1. Backend Setup (FastAPI + Python ML)

```bash
cd backend
python -m venv venv
# On Windows:
.\venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate

pip install -r requirements.txt
python -m app.seed
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

Backend API server runs at: `http://127.0.0.1:8000`  
OpenAPI Interactive Docs: `http://127.0.0.1:8000/docs`

### 2. Frontend Setup (Next.js + TypeScript + Tailwind)

```bash
cd frontend
npm install
npm run dev
```

Frontend Application runs at: `http://localhost:3000`

## 🎯 Challenge Track Coverage Summary

AquaOne explicitly covers **ALL SEVEN** challenge tracks through a unified data flow:

1. **Track 1: Citizen Science UX** (`/assess`) — Step-by-step visual stream assessment wizard using intuitive citizen terminology ("How clear is the water?") with photo, GPS, and voice logging.
2. **Track 2: Data-to-Insight** (`/dashboard`) — Stream Health Score (0–100), sub-indices, Recharts historical trends, upstream/downstream compare, and Leaflet GIS Map.
3. **Track 3: AI-Supported Assessment** (`/ai-review`) — AquaAI multi-agent validation, anomaly detection, image scan, explainable confidence scoring, and human-in-the-loop review interface.
4. **Track 4: Awareness & Storytelling** (`/insights`) — AquaStory narrative generator, interactive stream history timeline, before/after comparison, and interactive educational quizzes.
5. **Track 5: Community & Gamification** (`/challenges`) — Stream Guardian 5-level progression system, points engine, anti-spam quality rewards, community challenges, and leaderboard.
6. **Track 6: Resilience Informatics** (`/predictions`) — AquaPredict ML classifier predicting water degradation risk level (LOW/MEDIUM/HIGH), risk probability, explainable feature factors, and early alerts.
7. **Track 7: Digital Health Standards** (`/interop`) — One Health Bridge exposing OpenAPI docs and standard HL7 FHIR R4 JSON `Observation` resource mapping.
